The Posėdis workspace

An AI simulator of the Lithuanian Seimas: type a question, convene the full 141-member chamber, and watch a transparent, voiced plenary debate play back live. This workspace defines the product and the build — a Python application that serves a presentation-styled frontend over FastAPI.

🗳️
One rule above all. Per the Statute of the Seimas, every session must reach a recorded vote, and that vote must be transparent to the viewer: procedure, quorum (≥71/141), exact Už / Prieš / Susilaikė counts, a per-faction breakdown that reconciles with the totals, and the result. The domain model enforces this — see Architecture › Vote model.
