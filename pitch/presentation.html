01 — THE PREMISE

Rehearsing a debate used to be impossible.

You can't easily dry-run a parliamentary session before it happens. Communications teams, policy units, researchers and educators all hit the same wall: real deliberation is expensive to stage.

Posėdis turns it into a few minutes of compute — a deliberation sandbox where an entire institution argues a question out loud, on demand.

🎯

One question in

“Should Lithuania adopt a four-day work week by 2027?” — pick a topic and a language.

🏛️

A whole session out

50–60 time-stamped events: opening, ministry briefing, party speeches, cross-examination, recess, debate and close.

03 — DUAL GENERATION ENGINE

Run it on your laptop, or in the cloud.

Provider-agnostic by design. The same topic, language and audio settings drive both paths — switch with one toggle.

🔒 Local mode

Nothing leaves the device

  • Transcripts generated by your own Ollama server
  • Voices synthesised by a local Speaches TTS server
  • Zero per-token cost · full data residency
  • Per-speaker Kokoro voices, written to disk
$ ollama run llama3.1:70b
→ http://localhost:11434
☁️ Cloud mode

Maximum detail, no setup

  • Transcripts from OpenAI GPT-5-mini
  • Voices from gpt-4o-mini-tts
  • No local servers to run
  • API key stays in your browser only

05 — THE VOTE, IN THE OPEN

Every session reaches a vote — and you see all of it.

Per the Statute of the Seimas, deliberation ends in a recorded vote. Posėdis renders a public balsavimo protokolas: procedure, quorum, exact tallies, per-faction breakdown and the result — reconciled by the engine so the numbers always add up.

07 — BILINGUAL & ARCHIVABLE

Two languages. Every session saved.

🌐 Lithuanian & English

One switch regenerates the whole session — speeches, summaries and resolutions — in Lietuvių (default) or English. The choice is remembered between visits.

💾 Archive & replay

Transcripts auto-save to sessions/ as structured JSON via a small Node API, or download through the File System Access API. Reload and replay any past debate.
